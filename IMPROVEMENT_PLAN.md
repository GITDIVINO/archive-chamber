# План улучшений «Сна Борхеса»

Актуально на 10 августа 2026 года. Этот документ показывает состояние после
полного аудита геометрии. Подробные размеры зафиксированы в
[контракте](docs/GEOMETRY_CONTRACT.md), выполненные действия — в
[журнале](docs/GEOMETRY_IMPLEMENTATION_LOG.md).

## Завершённый фундамент

- [x] неизменяемый каталог полных книг `babel v3`;
- [x] безграничное циклическое размещение `world w3` по `q/r/level`;
- [x] 3840 физических слотов в каждой комнате w3;
- [x] совместимость опубликованных w2/w1-записей;
- [x] точное разделение каталожного адреса v3 и физического адреса w3;
- [x] поиск и reader не телепортируют игрока;
- [x] физические переходы ко всем шести соседям через две двери и проходы.

## Геометрический аудит — выполнено

### P0. Единый источник геометрии

- [x] правильный гекс задаётся одним радиусом и шестью каноническими стенами;
- [x] четыре стены несут четыре непрерывных шкафа почти от угла до угла;
- [x] две противоположные стены несут двери;
- [x] пол, потолок, колодец, балюстрада и коллизия используют согласованные
  вершины;
- [x] колодец занимает 70% площади пола, а не 70% линейного размера.

### P0. Убрать геометрические артефакты

- [x] удалены зависимые от угла камеры shader-отсечения пола и потолка;
- [x] удалены скрытые полноразмерные комнаты, пересекавшие активный гекс;
- [x] все шесть выходов содержат stencil-проёмы в изолированные локальные миры;
  полноразмерная геометрия не попадает в основной гекс;
- [x] прямой, левый и правый выходы имеют одинаковую глубинную композицию;
- [x] чужие оси vista не входят в основную сцену, а порталы композятся stencil-
  проходом без цветной панели;
- [x] боковой порог сохраняет точную позу камеры и не подменяет макет комнаты
  полноценной геометрией в момент перехода;
- [x] все шесть порталов существуют одновременно и не меняют видимость от
  направления камеры; вне frustum пропускается только GPU-отрисовка;
- [x] показанный через портал объект комнаты становится активным без повторной
  сборки;
- [x] горизонтальные proxy-комнаты и боковые fallback-preview полностью
  удалены из vista;
- [x] соседние комнаты готовятся до входа в проход; вход не создаёт геометрию
  и не переключает режим рендера;
- [x] маски учитывают depth, поэтому скрытые миры не видны над боковыми
  проёмами и сквозь стены;
- [x] дальние виды используют одну форму гекса и одинаковые материалы;
- [x] жёлтые заглушки и разрывы этажей исключены контрактом материалов.

### P0. Человеческий путь внутри монументального мира

- [x] дверь фиксирована на 4,2 × 3,6;
- [x] проход фиксирован на 4,5 × 18;
- [x] размеры прохода не умножаются вместе с шестикратным гексом;
- [x] автоматический тест сторожит отношение ширины прохода к его высоте.

### P1. Бесконечность без лишней стоимости

- [x] активная комната остаётся детальной и адресуемой по каждой книге;
- [x] дальние книжные стены заменены непрерывными полосами с редкими линиями
  корешков;
- [x] вертикальные комнаты не строят 38 400 отдельных книг;
- [x] дальние балюстрады упрощены до поручней и угловых стоек;
- [x] бюджет дальней геометрии зафиксирован тестом;
- [x] до портальной непрерывности контрольный кадр занимал 17 draw calls;
- [x] frustum-проверка пропускает невидимые из шести портальных проходов, а
  smoke-тест удерживает итоговый кадр в лимите 60 draw calls.

### P1. Свет и пространственная читаемость

- [x] белая схема заменена копчёной нейтральной оболочкой, тёмным деревом и
  одинаковой тёмной кожей всех книг;
- [x] книги, включая манифест, различаются только адресом и содержанием, а не
  случайным цветом; янтарное тиснение остаётся читаемым вблизи;
- [x] включены мягкие тени активной архитектуры;
- [x] книги принимают, но не создают тысячи мерцающих теней;
- [x] у двух выходов находятся две ограниченные локальные лампы, а множество
  дальних фонарей остаётся дешёвой эмиссией;
- [x] дальняя геометрия не отбрасывает тени;
- [x] дерево, кожа, матовый металл, латунь и штукатурка имеют разные roughness/
  metalness, но принадлежат одной тёмно-янтарной гамме;
- [x] мост разделён на доски, лестница получила косые тетивы, тёмные
  подступёнки и отдельные перила;
- [x] вертикальный туман и пыль скрывают технический предел генерации, не
  подменяя соседние гексы упрощённой комнатой.

### P1. Защита результата

- [x] unit-тесты размеров, топологии и адресов;
- [x] smoke-тест WebGL, reader, поиска и ввода;
- [x] проверки 4 шкафов, 2 дверей, 70% колодца и человеческого прохода;
- [x] проверки материалов, света, теней и бюджета дальней сцены;
- [x] равная ширина четырёх плеч перекрёстка, единая диагональная граница
  фаски у поверхности, линий и коллизии;
- [x] снимки тринадцати критических ракурсов: комната, четыре прямых и четыре
  диагональных направления из прохода, два кадра порога, вверх и вниз;
- [x] численная проверка положения и направления камеры до/после бокового
  порога, идентичности объекта комнаты и времени подготовки локального мира;
- [x] низкоразмерное пиксельное сравнение canvas за 1 см до и после порога.

## Следующий эффективный этап

### [готово] Вертикальное путешествие

Между уровнями ведёт одна лестница: мост через колодец и пролёт в его середине,
ровно на один этаж. `tests/stairs.test.mjs` пешком поднимается на два этажа,
обходит колодец на верхнем, спускается обратно и проверяет, что уровень
меняется только на единицу, свободные стены поворачиваются, в сцене одна
комната, а исходная комната возвращается с теми же томами.

### P1. Доступность и контраст

- проверить контраст при разных дисплеях и системном масштабировании;
- добавить понятное сообщение при недоступном WebGL;
- проверить reader и управление на очень узких экранах;
- сохранить клавиатурный фокус без навязчивой подсветки.

### P2. Долгий маршрут и память

- автоматизировать прогулку через десятки комнат и точный возврат;
- измерить память после повторных перестроений сцены;
- добавить отдельные закладки для книги v3 и физической копии w3;
- не смешивать пользовательские заметки с детерминированным текстом.

### Deferred. Сеть и публикация

Multiplayer, аккаунты, общая память, production-хостинг и мониторинг появляются
только после измерений локального маршрута. Сервер может синхронизировать людей,
но не становится источником книг или геометрии.
