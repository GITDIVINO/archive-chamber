# Дорожная карта «Сна Борхеса»

Актуально на 10 августа 2026 года.

## Текущий рубеж

- `babel v3` — замороженный каталог всех уникальных полных книг;
- `world w3` — безграничное размещение по `q/r/level`;
- одна комната w3 содержит 3840 физических томов;
- `w3;0;2;2;13;197` — физическая копия манифеста в начальной комнате;
- четыре стены гекса заняты непрерывными шкафами, две — выходами;
- центральный колодец занимает 70% площади пола и повторяется по вертикали;
- физические проходы дают путь ко всем шести соседям;
- поиск и v3-reader не меняют физическую комнату;
- текущая полная сцена строится локально, дальние виды используют лёгкий LOD;
- старые w2/w1-записи остаются совместимыми.

## Фаза 1 — математический и геометрический фундамент

- [x] заморозить v3 и w3 fingerprint;
- [x] проверить BigInt-координаты, циклическое размещение и 3840 слотов;
- [x] разделить каталожную и физическую запись;
- [x] построить правильный гекс: 4 шкафа, 2 двери, центральный колодец;
- [x] построить человеческие проходы и переходы между комнатами;
- [x] восстановить единообразный дальний вид, свет и мягкие тени;
- [x] добавить геометрические и визуальные регрессии;
- [x] опубликовать контракт и журнал аудита.

## Фаза 2 — вертикальный маршрут

- [ ] выбрать один физический способ перехода между уровнями;
- [ ] не перекрыть им центральный колодец и обзор этажей;
- [ ] вычислять только соседний уровень из exact w3 room id;
- [ ] сохранить поворот свободных стен на каждом уровне;
- [ ] проверить путь вверх, вниз и точный возврат;
- [ ] не строить одновременно несколько интерактивных комнат.

## Фаза 3 — ориентиры и локальная память

- [ ] раздельные закладки для v3-книги и w3-копии;
- [ ] история открытых записей с явным типом;
- [ ] локальные заметки, не входящие в текст книги;
- [ ] редкие детерминированные ориентиры без «официального» толкования;
- [ ] проверка доступности reader, управления и контраста.

## Фаза 4 — присутствие других игроков

- [ ] минимальный presence-прототип по exact w3 room id;
- [ ] частые пакеты содержат только ограниченную локальную позу;
- [ ] переход комнаты — отдельный серверно проверяемый шаг к соседу;
- [ ] BigInt-координаты не преобразуются в Number;
- [ ] rate limiting, reconnect и наблюдаемость;
- [ ] содержимое книг остаётся локальной математикой клиента.

## Фаза 5 — общая память

- [ ] публичные находки с явным различием v3 и w3;
- [ ] заметки и гостевая книга в отдельном хранилище;
- [ ] модерация, антиспам и политика хранения;
- [ ] нагрузочные тесты до выбора секторизации и провайдера.

## Фаза 6 — публичный релиз

- [ ] production-хостинг статического клиента;
- [ ] CI для unit-, smoke- и визуальных проверок;
- [ ] мониторинг ошибок и производительности;
- [ ] домен, TLS, privacy policy и эксплуатационный регламент.

## Принципы порядка

1. старый адрес никогда не меняет текст;
2. физическое место никогда не подменяется поиском;
3. путь сначала проверяется локально, потом синхронизируется сетью;
4. пользовательские данные существуют отдельно от книг;
5. новый этап начинается по измерениям, а не по ощущению.
