# contributing

## запуск

Проект не требует сборки. Из корня репозитория:

~~~
python3 -m http.server 8000
~~~

Затем откройте <http://localhost:8000>. На macOS достаточно дважды кликнуть `Launch Game.command`.

## проверки

~~~
npm test
npm run lint
~~~

`npm test` прогоняет регрессионные векторы каталога v3, инварианты размещения w2 и модель карты. `npm run lint` проверяет стиль и неиспользуемые символы. Обе команды запускаются в CI на каждый push и pull request.

## что нельзя менять без новой версии

Каталог v3 и размещение w2 заморожены строками-отпечатками:

- `V3_FINGERPRINT` в [babel-v3.js](babel-v3.js);
- `WORLD_FINGERPRINT` и `WORLD_BOOK_OFFSET` в [world-engine.js](world-engine.js).

Алфавит, размеры страницы и тома, смесь страниц, транспозиция манифеста и формула размещения образуют контракт. Любое несовместимое изменение требует нового префикса версии (`v4`, `w3`), а не правки на месте: иначе ранее опубликованные адреса начнут указывать на другой текст.

## границы модели

- содержимое книги определяется каталогом v3 и никогда не хранится и не генерируется случайно;
- физическое размещение w2 безгранично и циклически повторяет каталог;
- короткий тег `h-…` декоративен, допускает совпадения и не является адресом;
- в сцене одновременно существует только текущая комната;
- проход за свободной стеной не лежит в плоскости гексов: его длина — отделка и версии не требует, а его топология (четыре выхода, боковые в примыкающие гексы) — часть модели и требует.

## стиль

- ES-модули, без сборщика и без транспиляции;
- отступ 2 пробела, `.editorconfig` в репозитории;
- интерфейс в нижнем регистре, без декоративных кавычек в названиях;
- комментарии объясняют, почему код такой, а не пересказывают его.
